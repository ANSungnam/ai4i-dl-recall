# AI4I 2020 예지보전 딥러닝 — 고장 분류 + 판정 보류

AI4I 2020 데이터셋으로 기계 고장을 판정하는 Keras 신경망.
판정을 **불량 / 양품 / 판정 보류(사람 확인)** 세 가지로 내고,
보류 기준은 훈련 데이터 안의 5겹 교차 검증으로 코드가 스스로 정한다.

## 파이프라인

```
[확인]      데이터 읽기 → head()로 열 이름·앞 5행 확인
[전처리]    라벨 모순 27행 제거 → 입력 특성 6개 선택 → Type 인코딩
[분할]      훈련 80 / 테스트 20  (고장 비율 3.3%가 양쪽에 같도록 stratify)
[교차 검증] 훈련 80%를 5조각으로 나눠 4조각 학습·1조각 예측을 5번 (매번 새 모델)
            → 모든 훈련 샘플의 '처음 보는 모델 예측'으로 보류 기준 결정
[최종 학습] 훈련 80% 전체로 새 모델 학습
[평가]      테스트 20%로 1회 채점 — 보류 비율, 판정한 것의 정확도·정밀도·재현율
[예측]      새 데이터 1건 판정 (불량 / 양품 / 보류)
```

## 모델

- 입력: Type, 공기 온도, 공정 온도, 회전수, 토크, 공구 마모 — CSV 원본 6개 (계산으로 만든 열 없음)
- 은닉층 64-64(ReLU)에서 두 출력으로 갈라지는 멀티태스크 구조
  - `fail`: 고장 확률 1개 → 판정에 사용
  - `types`: 고장유형 확률 5개(TWF·HDF·PWF·OSF·RNF) → 보류 판단 후보, 고장 원인 제시
- 고장유형은 입력이 아니라 출력 쪽 정답으로만 사용 (입력에 넣으면 정답이 새어 정확도 1.0)
- 증강(class_weight) 미사용

## 판정 보류

판정 규칙은 두 단계이고, 어느 출력을 쓸지와 기준값은 **코드가 교차 검증 예측으로 선택**한다.
특정 고장유형을 사람이 지정하지 않는다.

1. 고장 확률이 [하한, 상한] 사이면 보류 — 모델도 헷갈리는 샘플
2. 고장유형 출력 5개 각각 '확률이 기준 이상이면 보류' 후보 — 쓸모없는 출력은 '사용 안 함'으로 정해짐

선택 규칙: 보류 비율 ≤ 10% 인 조합 중 **놓친 불량(미검)이 가장 적은 조합**
(같으면 판정 오류가 적은 쪽, 그다음 보류가 적은 쪽)

사람이 정한 것: 보류 허용, 보류 상한 10%, 선택 규칙, 후보값 범위

## 결과 (seed 0, 테스트셋 1,995건)

코드가 고른 보류 기준: 고장 확률 0.1~0.5 사이, TWF 확률 ≥ 0.01 (HDF·PWF·OSF·RNF는 사용 안 함)

| 지표 | 보류 없음 (0.5 판정) | 판정 보류 적용 |
|---|---|---|
| 판정 / 보류 | 1,995 / 0 | 1,786 / 209 (10.5%) |
| 정확도 (판정한 것 기준) | 0.9825 | **0.9922** |
| 정밀도 | 0.804 | 0.778 |
| 재현율 | 0.621 | **0.824** |
| 놓친 불량 / 오탐 | 25 / 12 | **6** / 8 |

- 기준선(전부 '정상'): 정확도 0.967
- 보류 없이 판정할 때의 상한: TWF 단독 11건은 원리상 못 맞혀 0.9945

불량 66건의 행방:

| 불량 종류 | 불량으로 맞힘 | 보류 | 양품으로 놓침 |
|---|---|---|---|
| OSF 과부하 (24) | 8 | 14 | 1 |
| HDF 방열 (17) | 11 | 5 | 1 |
| PWF 전력 (15) | 9 | 2 | 3 |
| TWF 공구 마모 (11) | 0 | 10 | 1 |
| TWF+PWF+OSF (1) | 0 | 1 | 0 |

- 입력만으로는 예측할 수 없는 TWF(마모 200~240분 사이 무작위 발생) 11건 중 10건이 보류로 걸러졌다.
- TWF 기준 보류 175건은 모두 공구 마모 173~246분 구간이라, 실제로는 '마모가 큰 공구는 사람이 확인'하는 역할을 한다.
- 남은 미검 중 PWF 3건은 모델이 고장 확률 0.0002~0.007로 확신하고 틀린 경우라 보류로는 잡을 수 없다.

## 결과를 읽을 때 주의

- **판정한 것의 정확도(0.9922)는 10.5%를 사람에게 넘긴 뒤의 값**이다. 보류 없는 정확도(0.9825)와 함께 봐야 한다.
- 교차 검증에서는 판정한 것의 정확도 0.9946이었고, 테스트에서 0.9922로 조금 낮아졌다.
- 결과는 seed 하나 기준이며, 같은 구조에서도 seed에 따라 보류 없는 정확도가 0.980~0.985로 흔들린다.
- 개발 과정에서 같은 테스트셋 결과를 여러 번 보며 구조를 바꿨으므로, 테스트 점수는 약간 낙관적일 수 있다.
