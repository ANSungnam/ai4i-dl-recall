# AI4I 2020 예지보전 딥러닝 (Predictive Maintenance)

AI4I 2020 데이터셋으로 기계 고장을 예측하는 Keras 신경망 분류기.
불균형 데이터(고장 3.3%)에서 **정확도 99.5%** 를 목표로, 가중치·증강 없이
원래 데이터 분포 그대로 학습하고 정확도·정밀도·재현율을 함께 평가한다.
입력은 원본 센서 특성 6개만 쓰고(계산해서 만든 열 없음),
고장 여부와 함께 고장 유형 5개(TWF·HDF·PWF·OSF·RNF)를 결론으로 내놓는 멀티태스크 구조로 학습한다.

## 파이프라인

```
[확인]    데이터 읽기 → head()로 열 이름·앞 5행 확인
[전처리]  라벨 모순 27행 제거 → 특성 선택(누수 열 제외) → 인코딩
[분할]    훈련 80 / 테스트 20  (stratify로 고장 비율 유지)
[표준화]  훈련셋 기준으로만 fit — 데이터 누수 방지
[학습]    가중치·증강 없이 1회 학습 (출력: 고장 여부 + 고장 유형 5개)
[평가]    테스트셋 정확도·정밀도·재현율 (고장 확률 0.5 기준)
[예측]    새 데이터 1건 판정 (학습 때 스케일러로 표준화 후)
```

각 단계의 이유는 `ai4i_dl_recall.py` 주석에 정리되어 있다.

- 고장 유형 열(TWF·HDF·PWF·OSF·RNF)은 정답의 세부 라벨이라 **입력에서 제외** (데이터 누수)
- 단, 라벨 정합성 검사에는 사용: 유형 표시와 Machine failure가 모순인 **27행 제거**
- **원본 특성만 사용**: 계산으로 만든 열(물리량 등)은 넣지 않음 — 이전에 시험한 물리량 3개 추가는 제거
- **멀티태스크**: 출력 'fail'(고장 여부) + 출력 'types'(TWF·HDF·PWF·OSF·RNF, 결론으로 함께 출력)
  - 유형 열은 입력이 아니라 출력 쪽 정답으로만 사용 → 데이터 누수 아님
  - 유형을 입력에 넣으면 Machine failure = 유형 중 하나라도 1 이라 정답이 샘 (시험 시 정확도 1.0)
  - 예측 때는 입력 6개만 필요, 정확도 평가는 'fail' 출력 기준
- **증강(class_weight) 미사용**: 고장을 부풀리면 재현율은 오르지만 과검이 늘어 정밀도가 떨어짐
- 조정할 값이 없어 검증셋을 두지 않고 80/20으로 분할
- `tf.keras.utils.set_random_seed(0)` 으로 실행 간 재현성 고정

## 데이터

[UCI — AI4I 2020 Predictive Maintenance Dataset](https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset) (CC BY 4.0)

`ai4i2020.csv` 를 내려받아 코드의 경로(`~/ws/robot/ai4i2020.csv`)에 두거나, `read_csv` 경로를 수정한다.

## 결과 (테스트셋 1,995건)

seed 0:

| 지표 | 값 |
|---|---|
| 정확도 | **0.9850** |
| 정밀도 | 0.860 |
| 재현율 | 0.652 |
| 목표 정확도 99.5% | 미달 |

고장 유형별 결론 (seed 0, 유형 확률 0.5 기준):

| 유형 | 실제 | 맞힘 | 오탐 |
|---|---|---|---|
| OSF 과부하 | 24 | 22 | 2 |
| HDF 방열 | 17 | 11 | 5 |
| PWF 전력 | 15 | 10 | 1 |
| TWF 공구 마모 | 12 | 0 | 0 |
| RNF 무작위 | 0 | 0 | 0 |

TWF는 200~240분 사이 무작위로 발생해 입력만으로는 원리상 예측할 수 없다.

시도 이력 (seed 0·1·2 평균):

| 입력 / 구조 | 정확도 | 정밀도 | 재현율 |
|---|---|---|---|
| 원본 6개 | 0.9808 | 0.811 | 0.550 |
| 원본 6개 + 물리량 3개 | 0.9837 | 0.853 | 0.616 |
| 원본 6개 + 물리량 3개 + 멀티태스크(유형 4개) | 0.9840 | 0.869 | 0.611 |
| **원본 6개 + 멀티태스크(유형 5개) — 현재** | **0.9821** | **0.848** | **0.561** |

물리량 3개는 원본 열을 계산해 만든 특성이라 제거했다. 제거 후 재현율이 0.611 → 0.561로 내려갔다.

이 테스트셋에서 TWF 단독 고장 11건을 빼고 모두 맞혀도 정확도는 1,984 / 1,995 = **0.9945** 이므로, 현재 분할에서 99.5%는 도달할 수 없는 목표다.

결과를 읽는 기준:

| 구분 | 정확도 | 설명 |
|---|---|---|
| 기준선 | 0.967 | 전부 '정상'으로 찍어도 나오는 값 |
| 이 모델 | 0.9850 | seed 0 |
| 이 테스트셋 상한 | 0.9945 | TWF 단독 11건 제외 전부 정답일 때 |
| 이론 상한 | ≈ 0.9957 | 공구 마모 고장(TWF)은 200~240분 사이 무작위 발생이라 입력 6개로는 원리상 예측 불가 |

이전 버전(class_weight ≈ 29배 + 재현율 0.9 목표)은 재현율 0.833, 정밀도 0.440이었다.
증강을 빼자 과검이 줄어 정밀도·정확도가 올랐고, 대신 놓친 고장이 늘었다.
